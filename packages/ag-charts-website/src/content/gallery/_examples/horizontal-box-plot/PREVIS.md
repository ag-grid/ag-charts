# PREVis Assessment: Horizontal Box Plot

## Overview

This example demonstrates a horizontal box plot visualization showing annual compensation distribution by role in an HR Analytics Dashboard context. The chart displays salary quartiles for six different job roles, with enhanced visual features including a company median reference line and role grouping indicators.

## PREVis Scores

### Purpose (7/10)

**What it shows:** The visualization effectively displays salary distributions across different organizational roles, showing minimum, quartiles, median, and maximum values for each position.

**Strengths:**

-   Clear business context with HR compensation data
-   Practical use case that resonates with real-world applications
-   Shows statistical distribution in an accessible format

**Weaknesses:**

-   Could benefit from showing outliers or actual data points
-   Missing context about sample sizes for each role
-   No indication of data collection methodology or time period specificity

### Relevance (8/10)

**Gallery fit:** Strong fit for demonstrating box plot capabilities in a business intelligence context.

**Strengths:**

-   Horizontal orientation is appropriate for role labels
-   Enterprise-focused example highlighting AG Charts' business analytics capabilities
-   Demonstrates a less common but valuable chart type

**Weaknesses:**

-   Could showcase more advanced box plot features (outliers, notches, variable width)
-   Limited interaction or dynamic features demonstrated

### Elegance/Effectiveness (6/10)

**Visual hierarchy and clarity:** Moderate effectiveness with some areas for improvement.

**Strengths:**

-   Clean, professional appearance with dark theme
-   Good use of grid lines for value reference
-   Rounded corners on boxes add visual polish

**Weaknesses:**

-   The star (★) notation for management roles is unclear and inconsistent
-   Background range annotations ("Entry Level", "Senior Level") are confusing as they don't align with actual role categories
-   Color scheme is monochromatic - could use color to encode additional information
-   Whisker caps could be more prominent

### Versatility/Visual Design (5/10)

**Adaptability and polish:** Limited versatility shown, moderate visual design quality.

**Strengths:**

-   Professional dark theme suitable for dashboards
-   Consistent styling throughout

**Weaknesses:**

-   No demonstration of color encoding possibilities
-   Limited use of AG Charts' advanced styling features
-   Could benefit from hover interactions or tooltips enhancement
-   Missing visual differentiation between role categories

### Innovation/Insightfulness (4/10)

**Novel approaches:** Limited innovation in presentation and insights.

**Strengths:**

-   Company median reference line adds context
-   Horizontal orientation is less common and works well here

**Weaknesses:**

-   Standard box plot implementation without creative enhancements
-   Background ranges ("Entry Level", "Senior Level") are misleading and don't correspond to the actual roles
-   No innovative data encoding or interaction patterns
-   Could explore comparative visualizations or trend analysis

### Simplicity/Specificity (7/10)

**Message clarity:** Generally clear but with some confusing elements.

**Strengths:**

-   Straightforward box plot representation
-   Clear axis labels and formatting
-   Focused on single metric (compensation)

**Weaknesses:**

-   The role grouping logic (★ for directors and managers) needs explanation
-   Background range annotations create confusion rather than clarity
-   Currency formatting could be more consistent

## Overall Score: 6.2/10

## Key Strengths

1. **Professional presentation** - Clean, dashboard-ready visualization
2. **Appropriate chart choice** - Horizontal box plot works well for categorical comparisons
3. **Business relevance** - Clear HR/compensation use case
4. **Statistical clarity** - Proper box plot implementation showing quartiles

## Key Weaknesses

1. **Confusing annotations** - Background ranges don't align with data logic
2. **Limited feature showcase** - Doesn't demonstrate advanced box plot capabilities
3. **Minimal interactivity** - Static presentation without enhanced tooltips or interactions
4. **Inconsistent categorization** - Star notation for management roles lacks clarity
5. **Monochromatic design** - Misses opportunity to use color effectively

## Actionable Recommendations

### Immediate Improvements

1. **Remove or fix background ranges** - Either align them with actual role categories or remove them entirely
2. **Clarify role categorization** - Use consistent visual encoding (color, icons) for role levels instead of stars
3. **Add sample size indicators** - Show number of employees per role
4. **Enhance tooltips** - Display detailed statistics on hover

### Data Enhancement

1. **Include outliers** - Show actual outlier points if they exist in the data
2. **Add temporal context** - Specify the exact time period or add year-over-year comparison
3. **More realistic data** - Current values seem artificially rounded and evenly distributed

### Visual Design Updates

1. **Color coding** - Use color to distinguish role levels or departments
2. **Interactive features** - Add ability to filter by department or seniority
3. **Comparison mode** - Allow comparison with industry benchmarks or previous years
4. **Better whisker styling** - Make whiskers and caps more prominent

### Feature Showcase Opportunities

1. **Variable width boxes** - Width could represent team size
2. **Notched boxes** - Show confidence intervals around medians
3. **Annotations** - Add specific callouts for notable insights
4. **Drill-down capability** - Click to see individual data points
5. **Export functionality** - Demonstrate chart export features

## Conclusion

While this example successfully demonstrates the basic horizontal box plot functionality, it falls short of showcasing AG Charts' full capabilities. The confusing background annotations and limited visual encoding reduce its effectiveness as a gallery example. With the recommended improvements, particularly around data clarity, visual design, and feature demonstration, this could become a compelling showcase of AG Charts' statistical visualization capabilities in a business context.
