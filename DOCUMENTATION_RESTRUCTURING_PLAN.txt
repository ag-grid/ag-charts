SECTION 12: TECHNICAL NOTES
================================================================================

Data Processing in AG Charts:
  - Data model located: /workspaces/ag-charts/packages/ag-charts-community/src/chart/data/
  - DataModel class: dataModel.ts
  - DataController class: dataController.ts
  - scopeCache utilities: /data-model/utils/scopeCache.ts, helpers.ts

fieldDotNotation Implementation:
  - Property defined in: commonOptionsDefs.ts (line 309)
  - Chart property: chart.ts (line 244)
  - API types: ag-charts-types/src/chart/chartOptions.ts (line 254)
  - Usage in DataModel: DataModel.ts (line 105+)
  - scopeCache check: scopeCache.ts (line 92)
  - Helper function: helpers.ts (getPathComponents, createPathAccessor)

Path Notation Parsing:
  - Supports dot notation: "a.b"
  - Supports bracket notation: "a['b']", a["b"]
  - Supports array indices: "a[0]"
  - Regex implementation: scopeCache.ts line 101+

Performance Notes:
  - suppressFieldDotNotation: true improves performance by skipping dot notation parsing
  - Useful for data with many nested properties or performance-critical scenarios
  - M4 algorithm for large dataset optimization explained in large-dataset-interactivity
  - applyTransaction() is 90%+ faster than full data replacement for small changes

Navigation Entry Point:
  - nav.json structure: sections -> children (groups) -> children (items)
  - Items have: type, title, path, and optional: isEnterprise, isPricingFeature
  - Groups have: type, title, children, and optional: isEnterprise, isPricingFeature
